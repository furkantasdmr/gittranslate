# Changelog / Değişiklikler

## 1.0.0

**English**
- 文→A bubble next to the GitHub app: tap it inside a repository to read the README in your language.
- Background preparation: README, *About* and latest release notes are translated before you tap; the bubble shows a progress ring and turns colourful when ready.
- Panel with About, README (headings, lists, tables, code, screenshots) and latest release with downloads.
- "More about this repository": project type, phone or computer, license in plain words, important folders.
- Share menu → *Explain repo* also works without the bubble.
- 19 translation languages; Turkish and English interface.
- In-app updates that keep the bubble's permission.

**Türkçe**
- GitHub uygulamasının yanında 文→A balonu: bir reponun içindeyken dokun, README'yi kendi dilinde oku.
- Arka planda hazırlık: README, *About* ve son sürüm notları sen dokunmadan çevrilir; balonda ilerleme halkası dolar, hazır olunca renklenir.
- Hakkında, README (başlıklar, listeler, tablolar, kod, ekran görüntüleri) ve indirmeleriyle son sürümü gösteren panel.
- "Bu repo hakkında daha fazla": proje türü, telefonda mı bilgisayarda mı kullanılır, lisansın sade anlamı, önemli klasörler.
- Paylaş menüsü → *Repoyu anlat* balon olmadan da çalışır.
- 19 çeviri dili; Türkçe ve İngilizce arayüz.
- Balonun iznini koruyan uygulama içi güncelleme.
